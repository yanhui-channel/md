## 决策及成本

按实施顺序归档，未完成外部验收前保留测试证据：

| 决策                                               | 原因与代价                                                                               |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 在现有专用 checkout 建功能分支                     | 工具不能定位嵌套仓库，未获新 worktree 授权；现有开发服务共享源码，所以不对它启用私有模式 |
| 后台增加有界 GitHub 请求/身份校验 helper           | 登录即需数字仓库 ID；每次读写仍须检查私有性和权限                                        |
| 仓库预先初始化 README                              | GitHub 不允许给空仓库创建引用；首次配置多一步，不做半成品引导                            |
| 图片使用 HMAC 校验凭据                             | 避免一次提交为每图重复调用 GitHub；密钥轮换需要原图重新上传                              |
| 历史列表只读固定 commit 与日期                     | 避免 20 条历史消耗 122 次请求；损坏的手工版本可能出现在列表，但打开/恢复会拒绝           |
| 未选择的本机草稿也记录代际；只有未选择稿允许空主题 | 保护旧稿与跨标签保存；旧稿需先打开一次确认主题                                           |
| 标签页保留独立读取基线，崩溃恢复另存               | 不让旧页面覆盖新稿；异常恢复可能多一份待人工确认的副本                                   |
| 统一观察有效主题，恢复主题固定到稿件               | 防止迟到设置覆盖原子恢复；私有样式通过稿件保存链路持久化                                 |
| 私有协调器/面板独立，普通账号入口不变              | 降低旧部署回归面；有两套刻意独立的账号面板                                               |
| 四语言文案归入现有 dialog 字典                     | 不新增无效类型文件或重复 store 文案；翻译归属继续在 dialog                               |
| 中文组合输入时 flush 拒绝；读取快照与接纳基线分开  | 保护候选文字与远端内容；保存等待输入完成，被拒绝的刷新需重试                             |
| 采用远端和另存都保留本机副本；另存会打开副本       | 不静默上传第二篇；用户需主动勾选新副本                                                   |
| 私有构建自托管全部已装高亮语法/主题                | 防止冷门语言离线失效；首次缓存下载更大，普通版 CDN 不变                                  |
| 更新保留旧静态缓存，只重开确认更新的窗口           | 旧标签页仍可能加载旧分块；历次版本消耗空间，备份后显式清理                               |
| 干净 Git 导出独立安装依赖用于构建                  | 不带入被忽略的私人素材；需要临时磁盘空间                                                 |
| 浏览器模拟 API 改为本机 HTTP 服务                  | WebKit 的 Service Worker 请求绕过 Playwright 路由；测试多一个临时服务，产品无模拟入口    |
| 私有图片存字节并兼容旧 Blob，普通版仍写 Blob       | WebKit 临时环境拒绝 Blob 持久化；增加临时内存，不回退到不支持字节的早期私有试验版本      |
| 清理在已确认的新页面执行，拒绝其他同源窗口         | 防止后台保存复活数据；需关闭其他标签/主屏幕窗口、离线服务已就绪，不改远端                |
| 审查使用继承模型、全新上下文                       | 工具禁止未经用户要求指定其他模型；不额外选模型，但保留独立审查                           |
| 真实 GitHub 行为留作外部验收                       | 审查者未判断真实 OAuth/PAT、并发和限流；模拟接口不能证明实际服务已通过                   |
| 免费托管与大陆网络留作实测                         | 打包只验证部署产物；免费额度和可用性可能不足，不自动付费                                 |
| iPhone 真机单独试用                                | WebKit 测试不能证明 Safari/主屏幕生命周期和存储回收；仍需约 15 分钟实际操作              |
| 浏览器测试与截图由实施者复核                       | 审查者未独立运行这些测试；这部分证据不等于第二次独立审计                                 |

## 独立审查与修复

全新上下文的审查者检查 `ed2f578..111dcb0`，发现两项严重、四项重要问题；全部按发布阻塞项处理。审查当时的结论为不可合并。实施者在一个修复轮次中补充失败用例并修复，未安排第二次审查，因此不能称为“独立复审通过”。

| 问题                                         | 修复与回归证据                                                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 保存期间新输入被误认成已保存，可能被远端覆盖 | 保存前固定文字、CSS 和主题指纹，写完后比较；文字/CSS 并发修改用例先失败后通过                                                        |
| 后台换库后，旧页面可能把内容上传到新库       | 正文与图片写入都携带预期仓库 ID；服务端写入前及提交重试时核对；缺失、不同仓库/分支均拒绝且无 Git 写请求                              |
| 只修改主题后立即切换文章，主题丢失           | 在切换前捕获独立主题快照；18px/17px 两篇快速切换用例先失败后通过                                                                     |
| 恢复的稿件忽略自定义 CSS 和代码配色          | 独立保存自定义 CSS，等待所选代码样式加载且不串到另一篇；下载失败允许原选择重试；编辑、导出、切换与重新打开均覆盖；普通版快照格式不变 |
| 远端 revision 未变时跳过实际文件验证         | 仍读取并核验正文和资源，同 revision 手工破坏不能显示同步成功                                                                         |
| 离线启动时初始化失败后不自动恢复             | 网络/前台恢复时重试初始化，保留显式暂停；手动同步等待正在执行的初始化                                                                |

完整浏览器回归另复现了历史保存与自动同步计时冲突：每 30 秒的本机历史备份曾重置上传等待时间。已区分仅历史变化与正文/主题变化，历史仍落盘，但不延迟排队上传；存储通知与同步订阅两项回归先失败后通过。不得通过手动触发同步来替代断网恢复的自动同步验收。
