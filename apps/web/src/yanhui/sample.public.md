# 衍辉 channel 排版示例

一篇文章，从一个具体的问题开始。

## 写作与排版

正文保持清晰的层次，**重要内容适当加粗**。标题序号随章节增删自动调整，不写入源文。

### 记录要点

- 留住事实和细节。
- 每段表达一个意思。
- 修改之前保留备份。

### 核对进度

| 工作     | 状态   |
| -------- | ------ |
| 整理素材 | 已完成 |
| 校对文字 | 进行中 |
| 检查排版 | 待处理 |
